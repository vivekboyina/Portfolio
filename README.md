## Getting started

### Prerequisites

- Node.js 18 or newer
- npm or pnpm

### Install dependencies

```bash
npm install
```

### Start the development server

```bash
npm run dev
```

The app will be available at the local URL printed by Vite.

### Create a production build

```bash
npm run build
```

### Preview the production build

```bash
npm run preview
```

### Format the project

```bash
npm run format
```
